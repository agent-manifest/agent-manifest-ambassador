# Agent Manifest Ambassador v0.1

Conversational generator for Agent Manifest declarations.

## What it does

Guides a user through 5 questions and produces a valid Agent Manifest JSON file.

## Flow

1. Identity
2. Purpose
3. Capabilities
4. Boundaries
5. Autonomy level

Output: downloadable `.json` manifest conforming to agent-manifest-spec.org/v1
